# Edubridge

An AI-powered education platform that creates study material in 22+ Indian languages. It works completely offline with no internet needed, so it runs on low-end devices with 4-8GB of RAM.

Built with React, TypeScript, Vite, and Tailwind CSS.

## What It Does

You pick a topic and a language. It generates curriculum-aligned content — notes, quizzes, and practice questions — all in your chosen language. Everything runs locally, no cloud needed.

## Getting Started

`ash
cd frontend
npm install
npm run dev
`

# Document Intelligence

A tool that reads legal and financial documents — contracts, invoices, court filings — and pulls out the important data. It works with both clean PDFs and scanned images.

Live demo: https://document-intelligence-abhati27.streamlit.app

## How It Works

Instead of trusting one model, it uses several — LayoutLMv3, Donut, a rules engine, and Tesseract as a fallback. Each one extracts data, and the system combines their results by confidence. Every field comes with a confidence score and a note on where it came from on the page.

## Getting Started

`ash
pip install -r requirements.txt
streamlit run app.py
